# 🔊 SpectraVeil Lab — Phòng Thí Nghiệm Giấu Tin Vô Hình

Phòng thí nghiệm 4 kỹ thuật giấu tin (Steganography) & pháp y nhị phân chạy cục bộ:

- **Mực tàng hình Unicode VS-256 (8-bit/char, khóa AES-256-GCM)** kèm **Bẫy truy vết rò rỉ Canary**.
- **Vẽ tranh / chữ mật / mã QR vào sóng âm `.WAV`** kèm máy soi phổ thác nước **Spectrogram FFT Realtime** & thu âm Air-Gap.
- **Đúc file Đa Nhân Cách Triple Polyglot**: 1 tệp hợp lệ đồng thời là ảnh `.PNG` + két Web `.HTML` mã hóa + kho nén `.ZIP`.
- **Kính lúp Pháp y số**: Cắt lớp Pixel **LSB Bit-Plane** & chụp X-Quang cấu trúc Byte/Chunk.

node server.js
